🎯 python-cv

A collection of Python + OpenCV projects showcasing skills in:

Object Detection

Object Tracking

Face Detection

Image Processing

Drawing & Annotation

Video Analytics

This repository is designed as a computer vision portfolio, perfect for learning, freelancing, and real-world applications.

📂 Project List
File Name	Description
objectdetection.py	Detects objects from images/video using OpenCV DNN. Draws bounding boxes & labels.
object_tracker.py	Tracks moving objects across frames. Useful for CCTV analytics, counting, and movement tracking.
face.py	Performs face detection using Haar Cascades / DNN. Works on images & live webcam stream.
blur.py	Applies blur, Gaussian blur, median blur, and image smoothing filters.
draw.py	Draws shapes, lines, text, rectangles using OpenCV functions. Helpful for CV annotations.
deduction.py	Image/video analysis script (remove noise, detect regions, or custom logic). (You can edit this later)
any other .py files	OpenCV utilities for image/video processing & demonstrations.

📦 Installation
